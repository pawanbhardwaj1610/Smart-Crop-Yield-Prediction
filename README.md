# Smart Crop Yield Prediction

This project predicts crop yield using a machine learning pipeline built around scikit-learn.

## Project structure

- `app/` contains training and prediction entrypoints.
- `src/` contains reusable machine learning components.
- `artifacts/` stores generated metrics and predictions.

## Run training

```bash
python app/train.py
```

## Run prediction

```bash
python app/predict.py
```
